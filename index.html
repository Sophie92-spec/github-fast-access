📖 使用说明
三步配置 hosts 加速 GitHub 访问
  1. 点击左侧 获取最新 IP，等待所有域名解析完成
  2. 在 Hosts 内容 卡片点击 生成 PowerShell 脚本
  3. 右键 以 管理员身份 运行下载的 .ps1 脚本
  4. 脚本自动备份原 hosts、写入新条目并刷新 DNS 缓存
  5. 重新打开浏览器访问 GitHub，速度应有明显提升
💡 也可手动：以管理员身份打开记事本 → 打开 C:\Windows\System32\drivers\etc\hosts → 复制 Hosts 内容粘贴保存 → CMD 运行 ipconfig /flushdns

  4. 粘贴内容，Ctrl+O 保存，Ctrl+X 退出
  5. 运行 sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder 刷新 DNS
