📖 使用说明
  1. 点击左侧 获取最新 IP 按钮，等待所有域名解析完成
  2. 切换到 Hosts 内容 标签，点击 生成 PowerShell 脚本
  3. 右键 以 管理员身份 运行下载的 .ps1 脚本
  4. 脚本自动备份原 hosts、写入新条目并刷新 DNS 缓存
  5. 重新打开浏览器访问 GitHub，速度应有明显提升
💡 也可手动：以管理员身份打开记事本 → C:\Windows\System32\drivers\etc\hosts → 复制 Hosts 内容粘贴保存 → CMD 运行 ipconfig /flushdns
