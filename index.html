📖 使用说明
  1. 点击上方 获取最新 IP 按钮，等待所有域名解析完成
  2. 点击 生成 PowerShell 脚本，复制或下载生成的脚本
  3. 右键 以 管理员身份 运行下载的 .ps1 脚本
  4. 脚本会自动备份原 hosts 文件、写入新条目并刷新 DNS 缓存
  5. 重新打开浏览器访问 GitHub，速度应有明显提升
💡 也可以手动操作：复制 hosts 内容 → 以管理员身份打开记事本 → 打开 C:\Windows\System32\drivers\etc\hosts → 粘贴保存 → CMD 运行 ipconfig /flushdns
  1. 点击上方 获取最新 IP 按钮，等待所有域名解析完成
  2. 复制生成的 hosts 内容
  3. 打开终端，运行 sudo nano /etc/hosts
  4. 在文件末尾粘贴内容，按 Ctrl+O 保存，Ctrl+X 退出
  5. 运行 sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder 刷新 DNS
