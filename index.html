📖 使用说明
  1. 选 DoH → 获取 IP 等待域名解析
  2. 切换到 Hosts 内容 → 生成 .ps1
  3. 下载后右键以管理员身份运行 .ps1
  4. 脚本自动备份原 hosts → 写入新条目 → 刷新 DNS
💡 也可手动：记事本打开 C:\Windows\System32\drivers\etc\hosts → 粘贴 → CMD 执行 ipconfig /flushdns
